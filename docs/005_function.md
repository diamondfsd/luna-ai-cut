# FreeCut 桌面功能规范

## 本地导出

### 目标

FreeCut 运行在 Luna AI Cut 的 Electron 桌面端时，导出完成后直接将文件保存到用户选择的本地目录，不再要求用户再次点击“下载”。

### 功能要求

1. 导出目录默认使用设置中的导出目录。
2. 用户可以在导出弹窗中重新选择目录，选择结果同步保存为新的默认导出目录。
3. 视频导出支持选择分辨率、帧率和码率：
   - 分辨率保持项目宽高比，可选择项目原始尺寸及缩放档位。
   - 帧率可跟随项目，或选择 24、25、29.97、30、50、60、120 fps。
   - 码率支持自动、VBR 和 CBR；VBR/CBR 可输入目标 Mbps。
4. 导出结果使用项目名称和时间生成文件名；同名文件自动追加序号，不覆盖已有文件。
5. 独立字幕模式下，视频和 `.srt` 文件使用相同主文件名并保存到同一目录。
6. 写入过程使用临时文件和分块传输；成功后再生成最终文件，取消或失败时清理未完成文件。
7. 完成页显示实际保存路径，并提供“在文件夹中显示”，不再显示“下载”。
8. FreeCut 独立浏览器版本没有桌面宿主能力时，继续保留浏览器下载作为兼容行为。

### 验收标准

- Electron 中执行普通视频、纯音频和独立字幕导出后，本地目录直接出现完整文件。
- 修改分辨率、帧率或码率后，渲染参数与界面选择一致。
- 目标帧率与项目帧率不同时，视频时长不变，并且不会错误使用无损直拷。
- 导出目录不可用、空间不足或写入失败时，界面进入失败状态并显示可理解的原因。
- 关闭完成页不会删除已经写入本地导出目录的文件。

## 文本、字幕与 HTML/CSS

### 数据模型

1. 标题、普通文字和字幕在时间线上统一使用 `type: 'text'`，不再维护独立字幕片段类型或嵌套字幕提示数组。
2. 字幕通过 `textRole: 'caption'` 标记用途，并通过 `captionSource` 记录转录、AI 字幕、字幕文件或内嵌字幕来源。
3. 每条字幕提示对应一个文本项目，直接使用项目的 `from`、`durationInFrames` 和 `text` 表达出现时间、持续时间和内容。
4. 字幕轨道仍可使用 `track.kind: 'subtitle'` 表达轨道用途，但轨道中的项目继续遵循普通文本项目结构。
5. 字幕来源元数据随项目保存，包括来源片段、媒体、文件格式、内嵌轨道号、语言、轨道名和编码信息。

### 编辑体验

1. 选中普通文字或已进入时间线的字幕时，右侧属性面板默认打开“文本”，文字内容位于布局、对齐和样式之前。
2. 字体、字号、颜色、粗体、斜体、下划线、对齐、背景、描边和阴影等常用能力继续提供可视化控件，用户不需要编辑源码。
3. 单段文字中的局部颜色和强调使用 `textSpans` 表达，预览和导出共享同一文本渲染路径。
4. 尚未写入时间线的转录字幕可在媒体片段的字幕面板中编辑；写入后按普通文本项目编辑，不再进入单独的字幕编辑路径。

### HTML/CSS 扩展

1. 高复杂度动态图文可使用独立 HTML 项目，支持 AI 创建和修改 HTML/CSS 源码。
2. HTML 项目在预览与导出中使用同一运行时和固定视口，避免编辑结果与最终视频不一致。
3. HTML/CSS 是复杂视觉表达的扩展能力，不替代普通文本和字幕的可视化编辑。

### 验收标准

- 导入字幕、内嵌字幕和语音转录生成的每条字幕均为普通文本项目，并带有完整字幕标记和来源。
- 字幕与普通文本使用同一时间线显示、选择、移动、裁切、拆分、预览和导出流程。
- 选中字幕后可立即编辑文字，并可继续调整全部普通文本样式。
- 保存并重新打开项目后，字幕时间、文本、局部样式和来源元数据保持不变。
- 普通文字编辑不要求用户接触 HTML/CSS；复杂 HTML 项目可以查看和编辑源码。
