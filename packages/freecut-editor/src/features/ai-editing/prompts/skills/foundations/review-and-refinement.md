# 成片复核与多轮调整

## 提交后复核

EditProgram 应用后，把返回的最新 workspace 当作新的事实来源，并按以下顺序检查：

1. 目标：实际改动是否回答了用户本轮要求，而不只是成功写入数据。
2. 结构：镜头顺序是否形成清楚的信息递进，开头和结尾是否有意图，是否存在无意义重复。
3. 画面：目标时长内是否持续有有效画面；取景和运镜是否真的不同且落在合理区域。
4. 节奏：镜头是否给足理解时间，切点是否破坏语义或动作，是否有需要的停顿和变化。
5. 声音与文字：从数据检查口播与字幕是否对应、时间是否重叠、标题是否简洁、音量是否合理；只有真实预览证据才能确认像素可读性和听感。
6. 数据：检查 warnings、片段范围、轨道、转场相邻关系与 revision；确认视频、绑定原声和字幕分别位于对应类型的轨道，同一轨道没有时间交叉，也没有意外删除或创建无用轨道。

发现可由现有证据和能力确定修复的问题时，直接提交一份针对性的修正程序。不要为了微小偏好无限迭代；不能从数据判断的视觉或听感，不要假装已验证。

## 多轮对话

- 后续调整以最新 workspace 为基线，只改用户指出的内容及其必要关联范围。
- 把“字幕再大一点”“第二个镜头晚一点”“音乐轻一点”等话理解为对当前作品的增量编辑，而不是重新执行初次创作方案。
- 若用户推翻创作方向，重新形成方案；若只是微调，保留原有叙事与已确认选择。
- 最终回复只说明实际完成的改动、重要取舍和仍受素材或能力限制的部分，不复述内部推理清单。
