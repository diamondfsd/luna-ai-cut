# 导演与剪辑判断

## 叙事与镜头

- 每个镜头只承担一个清晰的主要信息。先决定观众应该看哪里，再决定裁切、缩放、运动、文字和时长。
- 开场应尽早给出最有价值的画面、动作、问题或结果，但不要用与素材无关的夸张标题制造虚假钩子。
- 通过全景与特写、运动与静止、信息密度高低、长短镜头的对比建立节奏。持续运动和频繁转场不等于高级。
- 切换应由内容变化、动作、语义、音乐节拍或视觉对比驱动。没有理由时优先直接切；转场用于表达关系，不用于掩饰弱镜头。
- 同一静态素材可以通过不同取景形成镜头组，但每个取景必须指向真实可见区域，并有不同的叙事目的。运动应克制、方向明确，避免无意义来回漂移。
- 单张界面截图做特写时，应保留足够的相邻界面作为方位参照；画面证据显示存在大块空白区域时，不要把空白区放在镜头视觉中心，也不要用过高缩放把有效界面挤出画布。
- 画布比例决定构图。重要主体和文字应留在安全区域，避免边缘裁切；界面与产品内容首先保证可辨认，再追求动感。

## 时间与节奏

- 镜头时长由理解成本决定：复杂界面、长字幕和关键动作需要留出阅读或观察时间；过渡性镜头可以更短。
- 开始运动、停顿、切换和落点应形成节拍。必要的静止能让重点落地，避免整段都处于同样速度。
- 有音乐且节奏重要时，先获取节拍证据，再将主要切点靠近合适节拍；不要机械地每一拍都切。
- 有口播时以语义边界和呼吸为主组织镜头，避免在关键词或完整动作中间截断。需要定位原话时使用字幕搜索证据。

## 声音、字幕与文字

- 声音决定连续性。优先保护可懂的口播，再平衡音乐和素材声；不要让多个声音源在同一时段无目的竞争。
- 字幕忠于实际语音，不改写事实。按自然语义分段，保持足够显示时长，避免单条过长、断句生硬或相邻字幕互相覆盖。
- 标题只补充画面无法独立表达的信息。短、具体、可快速读完；不要用大量文字替代镜头叙事。
- 同类字幕应复用稳定轨道和角色，不因多轮修改不断新建轨道。修改已有字幕时优先更新对应片段。

## 诚实使用能力

- 只设计当前编辑协议能落地的剪切、重排、源区间、取景、运镜、标题、字幕、音量与转场。
- 不把文件名当作画面证据，不虚构人物、动作、界面区域、产品功能或声音内容。
- 不把程序中的标签或 intent 当作视觉结果；判断是否完成只能依据应用后返回的最新 workspace、diff 和 warnings。
- workspace 只能证明数据结构、时间范围和参数已经应用，不能证明文字在像素层面没有裁切、取景实际好看或声音听感正确。没有真实预览证据时，必须明确这是数据复核，不得声称已经完成视觉或听感验收。
