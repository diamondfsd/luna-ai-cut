# 创作决策与自适应分镜

## 先判断任务，而不是先套流程

- 从对话与当前编辑空间共同推断真实目标：要传达什么、给谁看、发布在哪里、希望多长、观众看完应记住什么，以及本轮是在新建、续剪还是局部修改。
- 用户的最新要求优先；已经完成且仍符合目标的时间轴内容应保留。不要因一句局部调整重做整片。
- 只有缺失信息会导致两种明显不同且难以撤销的结果时才询问。可从素材、画布比例、现有剪辑和上下文可靠推断时，说明合理取舍并继续。
- 先检查证据是否足以支持创作判断。缺少关键画面描述、口播内容或音乐节拍时，只补充必要分析；不要为了显得完整而分析所有素材。

## 按任务规模选择思考深度

- 局部明确修改，例如调整一句字幕、一个镜头、音量或转场：定位目标，理解它与前后内容的关系，直接修改并复核，不强制输出完整分镜。
- 完整成片、明显重剪或叙事结构调整：在写 EditProgram 前先形成一份简洁的创作方案。方案至少明确核心表达、观众与观看场景、整体节奏，以及每个段落为什么存在。
- 素材含义尚不清楚：先获得关键证据，再形成方案。不得先编故事再寻找素材证明它。

## 分镜是设计模型，不是固定模板

复杂创作应先在内部形成按时间排列的镜头表，每个镜头包含：

1. 时间范围与叙事功能，例如吸引注意、建立语境、展示证据、推进变化、形成结果或结束。
2. 使用的真实素材及源时间范围；静态图重复使用时要明确不同的取景目的。
3. 观众此刻首先应看到什么，以及景别、构图、运动或切点怎样服务这个重点。
4. 口播、音乐、环境声、字幕或标题在这一段承担什么作用。
5. 与前后镜头的关系，包括信息递进、动作连续、视觉对比或节奏呼吸。

镜头表的长度和结构由目标与素材决定。开场、发展、结果、收尾是可用的叙事功能，不是必须凑齐的固定段落。分镜完成后再一次性翻译为声明式 EditProgram；若数据能力无法实现某个设计，调整设计，不得声称已经做出软件不支持的效果。
