# 旅行 Vlog

你提供旅行 Vlog 的剪辑策略，由 `luna-editing-master` 负责结合用户要求和素材证据执行。

## 核心目标

让观众快速知道去了哪里、经历了什么、最值得记住的瞬间是什么。不要把素材简单按文件顺序拼接；优先建立地点和事件关系。

## 默认故事结构

1. 建立地点：城市、道路、建筑、风景或具有识别度的环境。
2. 进入行程：出发、抵达、移动、准备或开始活动。
3. 体验展开：人物行动、食物、手部、路牌、局部环境和细节。
4. 记忆点：人物反应、最具代表性的景色或最有情绪的瞬间。
5. 收尾：风景停留、离开、回望或一句简短感受。

## 镜头规则

- 优先组合远景建立环境、中景交代行动、近景补充细节。
- 选择不同角度和不同景别，减少连续重复画面。
- 人物反应、动作起点和动作结果尽量完整保留。
- 画面分析不足时不要根据文件名推断地点或人物。
- 相似镜头只保留最稳定、最清楚、最能推进故事的版本。

## 节奏规则

- 默认轻快，普通镜头可保持约 0.8 至 3.5 秒。
- 关键风景、人物反应和情绪停留可以更长。
- 不能为了快而切到看不清动作或无法阅读字幕。
- 用户要求“更快”时，优先缩短过渡和重复镜头，不先删除关键人物动作。
- 用户要求“更松弛”时，增加环境停留和自然声，不简单降低所有片段速度。

## 声音和字幕

- 保留少量环境声，让地点有真实感。
- 有口播或人物说话时，音乐不能盖住人声。
- 没有可靠音乐节拍证据时，不声称完成卡点。
- 字幕默认少量使用，只写地点、时间、事件和简短感受。
- 除非用户要求，不为每一个画面添加解释性字幕。

## 默认可调参数

- 画幅：用户没有指定时，根据素材和发布场景选择；短视频优先考虑 `9:16`。
- 节奏：平衡到轻快。
- 转场：低密度，优先硬切和少量淡化。
- 运镜：轻微推近或平移，不使用连续夸张运动。
- 色彩：自然、明亮、保留环境颜色。
