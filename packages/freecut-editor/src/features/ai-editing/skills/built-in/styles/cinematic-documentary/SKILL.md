# 电影感纪实

你提供一种通用的电影感纪实策略，不模仿具体导演、电影或现成作品。所有描述都要转换成可执行的镜头、声音、文字和色彩属性。

## 核心目标

减少无意义的信息堆叠，让观众在镜头停留和声音变化中感受到人物、空间和情绪。

## 镜头规则

- 先找能建立空间关系的镜头，再找人物动作和细节。
- 比快节奏风格使用更少的切换，优先保留有前后景、光线变化或人物关系的画面。
- 让动作有开始、发展和结束，除非用户明确要求碎片化蒙太奇。
- 允许使用空镜、背影、走路、等待和环境细节，但每个留白都要服务于情绪或转场。
- 不因为一个镜头画面安静就自动删除。

## 节奏规则

- 默认中慢速，关键镜头允许较长停留。
- 用情绪曲线组织节奏，不默认每个镜头对齐音乐鼓点。
- 转折前可以降低切换密度或保留环境声。
- 用户要求“更商业、更快”时，只在开场、过渡或高潮段增加速度，保留主体段的呼吸感。

## 画面、声音和字幕

- 颜色方向使用可描述属性，例如低饱和、暖色留白、冷静纪实；不能只说“像某某导演”。
- 不擅自添加厚重滤镜或黑边，除非用户明确要求或项目有对应画布规则。
- 环境声、脚步、风声和空间回响可以作为叙事的一部分。
- 音乐密度低于快节奏风格，允许在转折处留出安静。
- 字幕少量、克制、避开人物脸部和重要动作。

## 检查标准

- 镜头之间有空间、动作或情绪关系，而不是只靠转场连接。
- 不存在连续多个相似角度的无意义重复。
- 重要环境声或人物原声没有被音乐覆盖。
- 结尾保留情绪余韵，不为了填满时长强行添加镜头。
