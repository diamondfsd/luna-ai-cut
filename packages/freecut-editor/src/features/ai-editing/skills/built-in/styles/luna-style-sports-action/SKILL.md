# 运动与动作

## 镜头选择

- 先建立场地、方向和人物关系，再选择准备、动作、接触/变化和结果镜头。
- 保留动作起点、关键姿态和落点；相邻镜头要有景别、方向或主体变化。
- 反应、观众、器材和环境细节用于建立高潮，不替代关键动作证据。

## 节奏

- 预备段落可以较完整，动作段落提高切换密度，结果和反应留出确认时间。
- 变速优先作用于等待、准备或重复动作；使用 `luna.timeline.split` 后分别设置速度。
- 有可靠节拍时再做卡点；否则按动作落点和段落组织，不声称节拍对齐。

## 检查

避免黑帧、方向跳变、动作中断、字幕遮挡主体和过短镜头。声音以动作声、现场声和音乐层级为主，关键解说仍然优先。
