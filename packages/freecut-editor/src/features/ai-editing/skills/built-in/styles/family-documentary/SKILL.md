# 家庭纪录片

## 核心目标

记录人物和关系，而不是把家庭素材剪成广告。优先让观众看清楚谁在做什么、人物之间发生了什么，以及现场真实声音带来的记忆。

## 镜头选择

- 人物身份、表情、互动、拥抱、说话和动作结果优先。
- 尽量保留重要动作的完整过程，不从动作中间随意切走。
- 对相似素材，优先选择最清晰、人物关系最明确、声音最完整的片段。
- 如果人物识别证据不足，不根据文件名或用户模糊描述猜测身份。
- 对生日、成长、聚会等主题，按事件和人物关系组织，而不是只按画面漂亮程度排序。

## 节奏规则

- 默认平稳、温和，允许自然停顿和不完美。
- 少用强烈变速、连续快切、夸张转场和过度推拉。
- 用户要求“更感人”时，优先保留反应、停顿和声音，不使用廉价的重复慢动作。
- 用户要求“更快”时，先删除重复等待和无关空段，不能破坏关键动作的连续性。

## 声音和字幕

- 原声优先，音乐只做托底。
- 家人说话时，音乐必须降低，不能覆盖关键台词。
- 字幕默认少量使用：日期、地点、难以听清的台词或用户明确要求的句子。
- 不自动把人物身份、年龄或关系写成字幕事实，除非有用户提供或可靠证据。

## 检查标准

- 主要人物和事件关系清楚。
- 重要原声没有被音乐盖住。
- 不因为画面不够“漂亮”而删除有纪念价值的真实瞬间。
- 结尾可以保留自然停顿或家人反应，不强行套用商业片收尾。
