# 情绪化蒙太奇

## 核心目标

让一批素材围绕一个主题产生新的情绪关系，例如告别、成长、重逢、等待或自由。镜头可以跳出拍摄时间顺序，但每一次跳跃都应服务于主题。

## 开始前需要明确

- 用户想表达的主题或情绪。
- 哪些人物、地点或物件是主题的主要线索。
- 哪些声音、台词或音乐可以作为情绪锚点。
- 用户是否允许非线性排序。

如果用户没有提供主题，也没有足够的素材证据，不要擅自声称理解了某种复杂情绪；可以先做一个基于时间顺序的日常短片方案。

## 镜头选择

- 按人物、动作、色彩、地点、光线和声音建立可以互相呼应的镜头组。
- 允许重复同一人物或意象，但重复应当带来语义变化。
- 高潮前可以使用准备动作、空镜、手部、背影和环境细节建立期待。
- 高潮后保留反应、环境声或安静镜头作为余韵。
- 不要把模糊、遮挡或无关镜头仅仅因为“看起来有情绪”就强行保留。

## 节奏和声音

- 通过镜头长度、声音密度和画面变化形成渐强、停顿和释放。
- 不默认每个切点都对齐鼓点。
- 音乐、环境声和人物原声可以交替成为主导。
- 没有音乐分析结果时，不声称完成节拍设计。

## 字幕

- 字幕可以是少量章节、日期、台词或用户提供的文字。
- 不要把模型对情绪的判断直接写成“他此刻很悲伤”等事实字幕。
- 用户提供的诗意文字可以作为创作要求，但必须与实际素材关系相符。

## 检查标准

- 镜头之间存在人物、动作、意象、声音或情绪上的可解释关系。
- 非线性排序没有让观众完全失去时间和人物关系。
- 高潮和收尾有明显的节奏差异。
- 没有用未经证实的情绪、关系或故事补全素材。
