# 氛围电影感

## 镜头

- 先找建立空间关系的远景，再用人物动作、前后景和细节推进。
- 允许空镜、背影、等待、行走和环境细节，但每个留白都要服务于空间或情绪。
- 让动作有开始、发展和结束；不因画面安静就自动删除。

## 节奏和声音

- 默认中慢速，关键镜头可以停留更久；不默认每个切点对齐鼓点。
- 转折前降低切换密度，保留脚步、风声、房间回响和现场原声。
- 音乐密度低于快节奏风格，允许在转折处留出安静。

## 画面与文字

- 使用低饱和、暖色留白、冷静纪实或柔和高光等可观察属性描述色彩。
- 字幕少量、克制、避开人物脸部和重要动作。
- 当前没有专用 AI 调色工具时只输出色彩方案，不声称已经完成调色。
