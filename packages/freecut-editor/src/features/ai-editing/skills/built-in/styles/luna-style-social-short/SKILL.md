# 短视频社交风格

## 核心方向

前几秒让观众知道主体、结果或冲突，随后保持高信息密度，但不能快到看不清动作、字幕或产品。默认考虑 `9:16`，只有用户或发布场景支持时才改变画幅。

## 默认结构

1. Hook：最有信息量的真实画面或一句关键话。
2. 展开：用动作、细节、对比或口播解释主题。
3. 爆点：保留结果、反应、产品卖点或音乐高潮。
4. 收尾：一句结论、动作结果或自然结束，不强行加片尾。

## 镜头与声音

- 优先动作起点、动作落点、表情变化、产品细节和画面结构变化。
- 字幕短、对比清楚、留出阅读时间；口播时字幕跟随转写，不写未经证实的事实。
- 音乐推动段落，口播和关键原声优先；需要新声音时使用 `luna.audio.startSpeech` 或 `luna.audio.startMusic`，并用 `luna.audio.getTask` 轮询到完成后再处理生成结果。
- 用户明确要求卡点且有节拍证据时使用 `luna-technique-cutting-rhythm`；没有节拍分析时只按段落和动作组织。

## 检查

把剪映学习中心出现的关键帧、蒙版、文本、画中画、变速、HSL 和卡点视为可观察手段，不等于当前工具都已提供。缺少对应工具时给出方案，不声称完成。
