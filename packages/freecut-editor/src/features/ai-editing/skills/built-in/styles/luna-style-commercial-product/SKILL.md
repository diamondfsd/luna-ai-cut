# 商业产品与广告

## 核心目标

让观众快速看懂产品是什么、解决什么问题、如何使用以及为什么值得关注。视觉设计服务于信息和品牌，不用特效掩盖素材不足。

## 默认结构

1. 结果或产品特写：先展示最重要的卖点或使用结果。
2. 场景建立：说明产品出现在哪里、由谁使用。
3. 功能证据：用操作、细节、前后对比或字幕解释卖点。
4. 信任和收尾：保留真实反应、规格、品牌信息或用户明确提供的行动文案。

## 镜头与节奏

- 产品细节使用稳定近景，产品与环境关系使用中远景，避免连续重复角度。
- 切点优先跟随操作结果、画面变化和台词重点；转场保持低密度。
- 字幕短、层级清楚，不挡住产品关键区域；未经用户提供的规格、价格和功效不能写成事实。
- 音乐和音效托住动作，口播和产品操作声优先。

## 执行边界

用 `luna.media.read` 和 `luna.media.searchTranscript` 确认产品画面和文案，用 `luna.timeline.addMediaBatch`、`luna.timeline.addTextBatch` 和 `luna.timeline.setAudio` 执行已确认的安排。调色、三维包装、跟踪和复杂合成没有对应工具时只输出方案。
