# 快节奏 / 卡点

## 核心前提

只有在得到音乐节拍或明确的时间点证据后，才能说“卡点”。当前工具没有节拍分析能力时，可以先规划卡点方案，但必须说明还没有执行节拍对齐。

## 镜头选择

- 优先选择动作起点、动作落点、视线变化、镜头运动和画面结构明显变化的片段。
- 连续镜头尽量有景别、方向或主体变化。
- 短镜头必须达到最低可辨识时长，不能让字幕、人物动作或产品细节一闪而过。
- 有口播时，台词和关键信息优先于音乐节拍。

## 节奏规则

- 默认短镜头、高信息密度和快速进入主题。
- 有节拍网格时，优先把切点放在强拍或动作落点附近。
- 可以使用每拍、每两拍或每四拍切换，但必须根据镜头数量和音乐段落调整。
- 用户说“慢一点”时，先减少切点密度和保留更多动作过程，不直接把所有片段放慢。
- 用户说“更炸裂”时，优先增加镜头对比、动作匹配和音乐段落变化，不堆叠无意义转场。

## 声音和字幕

- 音乐是主要节奏来源，但不能盖住重要口播和人物对白。
- 有口播时，为音乐预留闪避空间。
- 字幕短、清晰、跟随台词或视觉重点出现。
- 需要卡点字幕时，先确认文字的显示时长足够阅读。

## 检查标准

- 所有声称的卡点都有节拍或时间点证据。
- 没有黑帧、过短片段和字幕来不及阅读的问题。
- 视觉变化与声音变化有关联，但不是每一帧都强行切换。
