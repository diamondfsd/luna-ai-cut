# 色彩与视觉风格

## 两层处理

- **基础校正**：曝光、白平衡、对比度、饱和度和镜头间一致性优先。
- **创意风格**：在校正稳定后再决定冷暖、低饱和、高对比、柔和高光或胶片感等可观察属性。

## 工作流

1. 读取画面证据和项目画幅，先找同一场景或连续镜头作为匹配基准。
2. 记录目标属性：亮度、色温、对比、饱和度、肤色、阴影和高光，不用“像某导演”作为参数。
3. 优先让相邻镜头观感一致，再对重点镜头做有限的创意偏移。
4. 检查肤色、天空、白色物体、暗部细节和高光是否失真。

## 风格示例的抽象方式

- 电影感：控制高光、保留暗部层次、低密度字幕和更有呼吸的镜头。
- 清透生活：自然白平衡、明亮中间调、适度饱和、保留环境颜色。
- 商业产品：主体与背景分离、色彩稳定、重点颜色有层级但不溢出。
- 复古氛围：降低锐利感和饱和度，使用有限的暖色或颗粒描述，不直接复制具体影片。

## 当前能力边界

当前 Harness 没有专用 AI 调色工具。可以根据证据输出调色方案和参数说明；除非已有结构化调色工具结果，否则不要向用户宣称已经完成校色或 HSL 调整。
