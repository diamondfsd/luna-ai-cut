# 剪辑节奏与镜头连接

## 先判断节奏依据

- 有可靠音乐时间点或用户明确给出的节拍，才可以执行或声称卡点。
- 只有音乐文件而没有节拍分析时，按段落、句子、动作落点和视觉变化组织节奏，并明确没有完成自动卡点。
- 有口播或对白时，语义完整和可听清优先于鼓点。

## 镜头连接

- **硬切**：信息变化、动作变化或观点变化时优先使用，干净且可控。
- **动作切**：在动作进行中切到相同方向或结果，隐藏切点并保持连续性。
- **匹配切**：匹配形状、方向、颜色、动作或声音；必须说明两镜头的实际匹配关系。
- **J Cut**：下一镜头的声音先进入，适合预告地点、人物或下一段话题。
- **L Cut**：画面切走后保留上一镜头声音，适合反应、回忆和空间延续。
- **淡化/溶解**：表示时间经过、情绪转折或段落结束；不要把每个镜头都用溶解连接。

## 节奏曲线

1. 开场快速给出人物、地点、结果或冲突。
2. 主体使用稳定的镜头长度，避免无目的地每拍切换。
3. 转折前可以减少切点或让声音先行；高潮处增加动作、景别或声音变化。
4. 结尾留出反应、环境声或最后一个完整动作。

## 执行和检查

- 用 `timeline.trim`、`timeline.split` 和 `timeline.add_media_batch` 执行已确认的切点；需要转场时先 `timeline.list_transitions` 再 `timeline.add_transition_batch`。
- 用 `timeline.set_audio` 处理声音桥接所需的音量和淡入淡出；不要用宿主代码猜测应该添加哪种转场。
- 检查黑帧、过短镜头、动作断裂、字幕来不及阅读和音乐盖住对白。
- 用户说“慢一点”时优先减少切点、保留动作过程或延长转场，不自动更换画幅和风格。
