# Luna 节奏与剪辑速度

## 适用场景

当用户要求更紧凑、更有冲击力、更舒缓、更像蒙太奇，或现有成片镜头长度单一时使用。节奏技能建立在粗剪和内容顺序之上，不用音乐或特效掩盖结构问题。

## 判断方法

- 先读取当前时间线和台词/画面证据，区分对白推进、动作展示、反应、环境交代和情绪停留。
- 通过长短、远近、静动和信息量的对比组织能量；不要把所有片段剪成同一种速度。
- 连续高密度镜头后检查是否需要一个定位或呼吸镜头；连续静态镜头缺少变化时，寻找动作、景别或信息变化。
- 开头建立兴趣，中段推进信息或冲突，结尾完成收束。短片也不能只剩一串无因果的高光片段。
- 不把固定秒数、固定镜头数量或固定节拍当成永久规则。用户平台和素材状态只能作为当前任务约束。

## 时间轴执行

- 使用 `luna.timeline.trim()` 精确调整停留长度，用 `split()`、`move()` 和 `remove()` 重排段落；每组修改后重新 inspect。
- 删除重复镜头前先确认它不承担空间定位、动作匹配或反应作用；优先减少重复信息，不盲目压缩所有停顿。
- 需要镜头运动时才使用 `addKeyframe()` 或 `setTransform()`；运动应强调主体或信息，不能让每个片段都持续缩放。
- 音乐节拍只能作为参考，不能替代对白语义、动作连续性和段落结构判断。

## 完成复核

- 速度变化与内容、情绪和段落位置一致，镜头不会因过快而看不清，也不会因过慢而失去必要信息。
- 修改后的相邻片段、关键动作和台词时间仍然成立。
- 没有把未验证的音乐节拍、视觉运动或主观“更好看”当作结构化完成证据；需要预览的部分明确列出。
