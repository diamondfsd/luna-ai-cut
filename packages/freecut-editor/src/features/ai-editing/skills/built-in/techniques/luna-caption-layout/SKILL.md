# Luna 字幕与版式

## 适用场景

当用户要求加字幕、修正字幕同步、突出重点词、制作口播字幕或检查字幕遮挡时使用。字幕应建立在剪辑后的时间轴上，不要直接复用粗剪前的时间戳。

## 字幕来源和分组

- 先读取当前项目和最终粗剪时间线；有现成转录时调用 `luna.media.searchTranscript()` 或 `media.read()`，没有可靠转录时先提交并等待 `transcript` 分析。
- 按语义、标点、停顿、说话节奏和画面变化分组。高信息密度内容使用更短的组，平稳表达允许更完整的语义组。
- 重点词可以通过样式或分组表达，但不能为了强调把一个完整句子拆成难以阅读的碎片。
- 每个字幕组都要有明确的开始和结束时间；后一组不能早于前一组结束。

## 时间轴和版式

- 字幕、标题和其他画面文字使用独立视频轨道，并确认其层级高于被覆盖的画面轨道。
- 使用 `luna.timeline.addText()` 创建字幕；时间使用当前时间轴绝对秒数，不能直接把素材源时间当成成片时间。
- `addText` 的 `x/y` 是文字框中心的归一化坐标，`width/height` 是归一化尺寸；常规底部字幕可使用接近 `x: 0.5, y: 0.84, width: 0.84, height: 0.1` 的版式，不能省略位置后让字幕默认堆在画面正中。
- 文本样式只使用当前 SDK 接受的 `style` 字段，不臆造未公开的字体、动画或特效参数。
- 字幕应避开安全区、主体脸部和重要动作；没有视觉预览或检测能力时，把溢出和遮挡列为待预览项。

## 修改和复核

- 批量添加前先确认字幕轨道；批量结果返回后重新读取时间线，检查字幕组是否重叠、持续时间是否为正、轨道层级是否正确。
- 粗剪或重排后不要沿用旧字幕的绝对时间；重新从剪辑后的台词和片段关系计算字幕范围。
- 修正字幕时优先修改准确的文本片段 ID，不把同名文字或数组位置当作可靠 ID。
- 只能报告结构化时间线确认的字幕已经加入或修改；文字是否出框、是否遮挡主体需要实际预览确认。
