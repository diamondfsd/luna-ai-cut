# Luna 声音剪辑

## 适用场景

当用户要求配乐、音效、配音、对白更清楚、声音衔接更自然或删除原声时使用。声音工作建立在结构稳定的粗剪上；不要用音乐掩盖对白或镜头选择问题。

## 声音结构

- 先读取项目、时间线、原声关联关系和已有音频轨道。对白是第一优先级，环境声、反应声、音效和音乐按内容需要加入。
- TTS 使用 `luna.audio.startSpeech()`；背景音乐使用 `startMusic({ model: 'small-music' })`；音效使用 `startMusic({ model: 'small-sfx' })`。所有任务都必须轮询 `luna.audio.getTask()`。
- 任务只有在 `status === 'completed'` 且返回有效 `mediaId` 时才能加入时间线；`failed` 时返回结构化错误并停止使用该结果。
- 配音、音乐和音效使用独立音频轨道。视频原声的伴侣音频保留其关联，除非用户明确要求解除或删除。

## 连续和混音

- J-cut 用下一段声音提前制造预告或空间连接；L-cut 让上一段声音延续到下一画面。只有有明确叙事或空间目的时才使用。
- 音频切点检查波形连续性；在必要处使用 `setAudio()` 的淡入/淡出，避免点击声和突兀断裂。
- `setAudio().volume` 使用 dB，`0` 是正常音量，不是静音。静音使用 `mute()` 或 `setAudio({ muted: true })`，并在返回数据中确认结果。
- 音乐和音效不能盖住对白重点；没有自动 ducking 能力时，通过可验证的音量设置和独立片段表达方案，不假装完成自动混音。

## 时间轴执行

- 通过 `addTrack()` 创建独立音频轨道，再用 `addMedia()`、`move()`、`trim()` 和 `setAudio()` 放置或调整媒体。
- 只删除伴侣音频时，先 `unlink({ itemIds: [audioId] })`，再 `remove()`；删除前重新确认准确的音频 ID。
- 每组声音操作后调用 `luna.timeline.inspectContext()`，确认轨道、片段范围、关联关系和音量。

## 完成复核

- 对白、环境声、音乐和音效的层级与用户目标一致，切点没有明显结构错误。
- 所有生成音频都已明确完成，失败任务没有进入时间线。
- 只能报告结构化数据确认的轨道和音频参数；缺少实际播放或响度测量时，明确说明听感尚未完成最终验证。
