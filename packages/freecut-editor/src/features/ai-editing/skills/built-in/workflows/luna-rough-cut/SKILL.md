# Luna 转录优先粗剪

## 适用场景

用户要求粗剪、去掉废话、压缩口播、整理访谈、按主题重排，或需要从长素材中提取可用段落时使用。它只负责内容结构和第一轮取舍，不负责最终字幕样式、配乐和视觉包装。

## 工作步骤

1. 先读取当前项目、时间线和素材清单。长视频先提交 `luna.media.analyze({ mediaIds, kind: 'transcript' })`，轮询完成后使用 `media.read()` 的 `transcript.nextOffset` 分页读完带时间的对白；不要先对长视频做整片视觉分析。
2. 根据完整转录先选出符合用户目标时长的对白源区间。需要画面确认时，再对同一素材提交带 `timeRanges` 的 `kind: 'visual'` 分析，每段只覆盖对白附近的有限范围。
3. 把候选内容分为保留、待确认和删除三类。填充词、口吃、重复观点和静音只能结合完整上下文判断；停顿、呼吸、笑声和连接句可能承担叙事作用。
4. 优先保留能推进主题、说明因果、展示反应或完成观点的段落。重复内容保留表达更清楚、情绪更自然或上下文更完整的版本。
5. 按成片顺序组织段落，再处理片段的起止点。先完成结构，再进入字幕、音乐、转场和调色。

## 时间轴执行

- 使用 `luna.timeline.split()`、`trim()`、`move()` 和 `remove()` 进行结构编辑；时间参数按共享契约使用时间轴绝对秒数。
- 拆分、删除或移动后重新读取 `luna.timeline.inspectContext()`，不要继续使用已经失效的片段 ID 或原始素材时间戳。
- 带原声的视频删除伴侣音频前先 `unlink()`，再 `remove()`；不确定的候选保留在项目中，不直接永久删除。
- 批量操作前先确认轨道和关联关系；批量结果异常时停止后续操作并重新读取项目。

## 完成复核

- 粗剪后的台词顺序、语义和动作关系成立，没有因为只按静音或音量删除有效内容。
- 删除、拆分和移动后的片段范围与关联关系符合方案。
- 每个异步分析任务都有明确的 `completed` 或 `failed` 结果；失败分析不被继续使用。
- 只报告已经通过结构化时间线结果确认的修改；字幕、音乐、画面质量和最终导出留给后续技能。
