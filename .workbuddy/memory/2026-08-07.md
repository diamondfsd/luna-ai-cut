## 修复剪辑页导航栏消失问题

- **问题**：进入剪辑菜单（/video-editor）后顶部导航栏消失，项目列表页无法返回其他 Luna 页面
- **根因**：`nav.css` 中 `body.freecut-route-open:not(.freecut-editor-open) .global-nav { display: none }` 规则在项目列表页（`freecut-editor-open` 未添加）时隐藏了整个导航栏
- **修复**：删除该 CSS 规则；同时清理 `VideoEditorPage.tsx` 中不再使用的 `freecut-route-open` class 管理代码
- **行为**：列表页正常显示 Luna 导航；编辑页（`freecut-editor-open` 存在）通过现有 CSS 规则隐藏默认导航、显示编辑器工具栏
- 涉及文件：`src/styles/nav.css`、`src/pages/VideoEditorPage.tsx`
