# 全局 AI 助手维护规范

先读 [目录索引](README.md)。

- 唯一可见入口是顶部导航栏最右侧「AI 助手」。面板为右侧非模态浮窗，不挤压页面；不在导演计划或 AI 剪辑页面重建独立聊天框、进度面板或启动按钮。
- 组件负责需求输入、输入区选择 Agent、顶部历史及进度展示；不生成业务提示词，不直接调用应用启动协议，不实现领域工具策略。
- 通过 `window.luna.externalAgent` 将原始需求交给主进程协调器。聊天面板不提供打开或下载应用按钮。
- 进度与历史按 sessionId 隔离，按 sequence 合并去重。订阅与初始读取须防止漏事件、旧请求覆盖新状态和卸载后更新。
- 历史记录只读，选中后隐藏输入框，不提供修改请求或删除记录操作；提示到该记录实际使用的 Agent 继续聊天。活动任务可保留停止和导出确认控制，不能控制其他会话，重启后不能把存档状态当活动状态。
- 不提供功能/任务类型下拉，不在前端分类需求。全局发送不指定 purpose，由外部 Agent 读取统一技能索引后选择；旧跨窗口上下文中的 purpose 只保留兼容，不成为用户选择。
- 明示后续在所选外部 Agent 中沟通；Luna 展示任务进度和结果，不宣称已同步外部完整聊天。
- 控件使用 `src/ui`，面板样式保留在本目录并由组件引入。文案保持精简，遵守根目录规则。

事件合并已有覆盖见 `scripts/test-external-agent-adapters.mjs`；历史/主进程风险见 `scripts/test-agent-conversations.mjs`。静态文案与布局不堆专用测试，不自行启动 UI 验收。
