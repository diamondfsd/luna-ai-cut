# D3 调色蒙版固定效果集

本目录保存调色蒙版 D3 的固定网络图片测试集，共 40 张：天空、水面、人物、主体和树木各 8 张。它用于模型效果、失败模式和性能里程碑，不作为日常单元测试输入，也不要求每次代码改动运行全量推理。

## 目录

- `images/sky/`：天空与云层、山体、桥梁、建筑、雾天边界。
- `images/water/`：波浪、倒影、瀑布、船只遮挡、水冰混合和浅水。
- `images/person/`：单人、多人、坐姿、小目标、人与动物相邻、骑行和人群。
- `images/subject/`：动物、花、汽车、自行车、伞、收音机和镂空建筑。
- `images/tree/`：密集枝叶、孤立树、逆光、多树重叠、雾天和特殊树冠。
- `manifest.json`：每张图的固定文件页、下载 URL、作者、许可、尺寸、字节数和 SHA256。

图片均为 Wikimedia Commons 的 `1280px` JPEG 缩略图。manifest 中的 URL 和 SHA256 一经进入固定效果集就不静默替换，避免测试失败时自动换成另一张更容易的图片。

## 恢复与验证

图片缺失时，在应用仓库根目录运行：

```bash
node scripts/fetch-mask-effect-dataset.mjs
```

脚本会按 manifest 恢复缺失或损坏的文件，并要求 SHA256 与固定清单一致。`--resolve-sources` 会重新解析来源并重写 manifest，只用于明确调整数据集，不应加入普通测试流程。

## 使用规则

- 日常开发先使用 1 至 2 张相关类别图片冒烟，避免每次运行 40 张模型推理。
- D3 模型里程碑统一运行 40 张，记录空结果、明显误选、边界问题、修补成本和各阶段耗时。
- 新失败样本只有在能代表新的高风险场景时才加入；不要为了增加测试数量扩充图片。
- 原始图片不复制到规划仓库，规划文档只引用本目录编号和结果记录。

## 批量评测

模型文件由应用下载器准备，不提交到仓库。指定模型缓存目录后运行：

```bash
node scripts/evaluate-mask-effect-set.mjs --model-dir <模型目录>
```

评测器按产品固定路由调用 SegFormer B0、YOLO26s-seg 和 BiRefNet General Lite，输出每张图的耗时、蒙版覆盖率、输出哈希和错误状态。运行结果保存在被 Git 忽略的 `test-results/color-masking/`，避免把临时蒙版当作人工验收后的金标。

自动结果只能识别进程失败、错误尺寸、空/近空/近全图和不确定输出。目标语义、细边界、倒影误选、背景误伤和手动修补成本仍需在里程碑集中验收。
