# 启动动画

`start-page.mp4` 来自用户提供的项目根目录同名裁剪视频，尺寸为 800×590，24 fps，时长约 5 秒。启动资源仅移除了音轨，视频未重新编码。

动画使用无边框窗口循环播放，保留视频原有背景，窗口圆角外透明。MP4 本身不带透明通道。

视频与功能样式通过 Vite 的 `?inline` 作为启动页面内容载入，不依赖网络、外部资源路径或主界面的加载进度。

设置和设备列表初始化完成、主界面完成绘制后发送启动完成通知，主窗口显示并关闭动画窗口。不会等待视频播完，也不会在固定时间后提前结束动画。相机连接、媒体扫描和模型加载属于后续业务操作，不阻塞启动。

启动窗口属于安装包的引导入口，更新此功能需要完整安装包，仅更新业务页面不能替换已安装的引导入口。

非界面验证：`node scripts/test-startup-window.mjs`。
