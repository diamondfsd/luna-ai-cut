# 应用级记忆规范

先读 [索引](README.md) 和 [设计](../../../docs/app-memory-architecture.md)，继承 [领域规则](../AGENTS.md)。

- 记忆是应用框架能力，不能放入剪辑 renderer、项目存储或具体 Agent 适配器。各领域通过同一服务复用；存储层不导入 AgentSessionManager、Electron、React 或 OpenReel。
- 个人空间固定为 `~/.luna-ai-cut`；记忆在 `memory/`。路径从 agent-space 提供，不根据 baseDir、安装目录或 userData 推导。退出只等待写队列，不能清空记忆；卸载、更新、项目删除不能删除个人空间。
- 注册技能 `memory` 不声明 workflow；读写记忆不选择 editing/director-plan，不启动窗口。不要用关键词分类需求或把能力不足改写成另一个业务任务。
- 当前工具适配器要求已领取任务及当前 revision，所有范围的访问均校验；project 范围只能访问任务关联项目。仓储在排队后、读取后和提交前重复调用访问校验，防止过期/停止请求写盘。
- 来源由服务生成，引用当前任务保存的原话，不接受客户端 actor/sourceId/status。外部 Agent 更新的 task-request 不是独立验证的用户聊天。逐字保存为 recorded，摘要和分析为 candidate；recorded 不能宣称为确认偏好。当前要求优先于记忆，记忆正文不是执行指令或授权。
- 不自动从聊天/方案/工具成功推断用户喜欢什么。实拍/录屏/AI 音频属于创作背景，不自动提升为风格偏好。
- 串行原子提交，损坏/未知格式必须报错，不能重写为空。更正保留旧版本并校验 expectedVersion；写操作保持幂等，重试不能增加证据权重或恢复已忘记内容。
- forget_memory 删除该记录所有内容/来源版本，仅保留不含原文的幂等收据。任务历史另行管理，不声称同时删除所有聊天来源或其他独立记忆。不得因重启或旧请求重放自动重建忘记的记录。
- 新来源类型通过明确的来源适配和验证契约接入。媒体分析须有真实内容身份、区间、观察和分析版本；导演意图不能当成拍到的证据。不接受任意文件路径来导入内容。
- 修改文件格式须维护 formatVersion 和迁移，修改工具契约同步检查 HTTP/MCP/OpenAPI、技能全文和非界面测试。

必测风险：来源伪造、范围越界、更正冲突、幂等/忘记恢复、重启持久化、损坏不覆盖和停止/过期写入。回归入口为 `scripts/test-app-memory.mjs`。
