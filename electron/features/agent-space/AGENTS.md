# Agent 个人空间规范

先读 [索引](README.md)，继承 [领域规则](../AGENTS.md)。

- 用户选定根目录为 `~/.luna-ai-cut`，不能更名为 .luna-ai-cut-agents，也不能挂到安装目录、userData、缓存或项目 baseDir。所有新 Agent 持久能力使用本目录公共路径入口。
- 生产 home 由系统提供；测试注入隔离目录，所有 Agent 数据使用同一测试 home。不接受 renderer 提交的任意目录作为可信个人空间。
- 软件退出仅清除属于当前进程的服务发现记录；卸载/热更新/重装/项目清理不得删除用户记忆和历史。不添加“自动清理整个根目录”。
- 迁移必须先验证、原子提交、保留旧来源；已存在的新文件优先，损坏不能回退覆盖。不得静默丢弃、合并覆盖或重新导入用户已经删除的记录。
- 持久数据与运行时发现文件分开管理。新能力建独立子目录并更新索引、服务装配与迁移测试；业务数据格式不塞入公共路径 helper。
