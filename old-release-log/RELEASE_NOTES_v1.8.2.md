# v1.8.2

## Bug 修复

- **改善相机 Wi-Fi 连接失败处理**：自动连接失败时明确提示用户复制密码并在系统 Wi-Fi 中连接相机热点，完成后返回应用重试。
- **保留手动连接所需信息**：连接失败后继续显示相机热点名称，并支持复制 Wi-Fi 密码或重新输入密码。
- **修复 macOS Intel 下载入口**：落地页独立展示 Apple 芯片和 Intel 芯片的 macOS 安装包，避免用户找不到 x64 下载地址。

## 改进

- **简化设备连接提示**：缩短连接页中的状态、诊断和磁盘说明，让处理步骤更清晰。
- **优化跨平台发布检查**：正式 macOS Release 包必须完成 Developer ID 签名、Apple 公证和票据装订后才能上传到 GitCode。

## 其他

- 更新项目版本至 `1.8.2`。
