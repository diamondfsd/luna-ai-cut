# v1.8.5

## 新功能

- **DJI Pocket 实时预览**：支持 DJI Pocket 设备的实时预览和媒体访问。
- **按次选择传输目录**：下载素材时可以为当前操作选择目标目录。

## 改进

- **Luna Wi-Fi 连接**：自动切换 Wi-Fi 失败后只尝试一次，并提示用户在系统 Wi-Fi 中手动连接后检查。
- **连接诊断**：记录 Wi-Fi 状态变化和相机控制通道握手结果，便于定位连接问题。
- **连接页布局**：整理 Wi-Fi 失败提示、名称和密码展示及诊断入口，减少重复信息。

## Bug 修复

- **修复 DJI 预览链路**：改善相机连接、UDP 传输和预览状态处理。
- **保护下载目录**：下载到未配置目录前增加明确提醒。
