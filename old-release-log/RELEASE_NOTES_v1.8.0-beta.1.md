# v1.8.0-beta.1 - 安装包发布说明

## 新功能

- **新增水印设置**：支持在编辑和导出流程中管理水印。
- **完善相机实时预览**：优化视频流传输、预览显示和连接流程。

## Bug 修复

- **修复 DJI 相机连接问题**：改善设备连接和状态切换逻辑。
- **修复水印设置保存问题**：确保设置修改后能够正确保留。
- **修复图片导出 HDR 信息**：保留 HDR 增益图等元数据。
- **修复色彩调整问题**：改善色彩和调色相关处理结果。

## 改进

- **优化 Windows 视频导出**：默认使用原生 GPU 导出路径。
- **改善媒体下载和导出稳定性**：完善文件处理、元数据和错误恢复逻辑。
