# v1.8.1

## 新功能

- **支持 Luna Pro**：新增 Luna Pro 的设备识别、连接、媒体管理、水印资源和实时预览支持。
- **实时预览增强**：支持全屏查看、视频静音和更稳定的画面解码。
- **更多相机接入能力**：完善 DJI 相机媒体浏览、下载、删除以及连接流程。

## Bug 修复

- 修复纯图片素材在 Pixel Flow 预览中动画不再推进的问题。
- 修复部分 WebGPU 预览、调色和播放过程中的画面异常。
- 改进 Insta360 相机 Wi-Fi 保活和连接帧处理，降低预览过程中断开的概率。
- 修复 DJI Pocket 4P 设备识别和媒体协议中的兼容性问题。

## UI 变化

- 仅 Luna 系列设备显示导航栏右上角的相机实时预览入口，DJI 等暂不支持实时预览的设备不再显示该图标。

## 其他

- macOS 原生辅助工具改为在打包阶段预编译，用户安装后无需安装 Xcode 或开发者工具。
- 完善 macOS、Windows 三平台安装包和热更新资源的发布流程。
- 更新项目版本至 `1.8.1`。
